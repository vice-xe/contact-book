# Contact Book

A simple command-line Contact Book built with Python.

## Features

- Add contacts
- View contacts
- Search contacts by name
- Delete contacts
- Save contacts using JSON
- Load contacts when the program starts
- Handles invalid menu input
- Case-insensitive search and delete

## Technologies

- Python
- JSON

## How to Run

Make sure Python is installed, then run:

```bash
python main.py
